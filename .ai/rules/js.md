# Js

## Pure Tailwind v4 + shadcn; committed "stage" appearance (Nexus Homepage 06 concept)
The voter UI is pure Tailwind v4 + shadcn (`components/ui/*`) with ONE committed look, adapted from the stakeholder-supplied Nexus event template (`index6.html`) while keeping the ACE palette: dark **night** stage grounds (hero, page banners, weekly-draw section, CTA, footer, login/status) alternating with **white** and **paper-soft** content bands; primary actions use the `bg-brand` gradient (violet→pink) with white text and an `ArrowRight` carrying `cta-arrow` (diagonal, straightens on hover). shadcn tokens are mapped identically on `:root` and `.dark` — do not build dark-mode variants. Tokens in `resources/css/app.css` `@theme`: `paper`/`paper-soft` (ivory grounds), `night`/`night-soft` (stage grounds / stat boxes), `ink` (text on light), `veil`, `mist`, `gold` (text on light), `gold-fill` (stat numbers + accents on night), `gold-soft`, `ember`, `violet`, `pink`. Utilities: `bg-brand`/`bg-brand-reverse`, `text-brand` (gradient text on light), `text-sunrise` (pink→gold gradient text on night — the hero highlight word), `bg-spotlight` (3-stop, avatar story rings + progress bars), `bg-rings` (concentric ring pattern behind night sections), `glass` (white/10 panel on night), `shadow-lift`, `shadow-glow`, `sweep` (gradient fill-from-left hover), `text-display-xl/lg/md`. Fonts: Figtree (body) + Bricolage Grotesque (display) + Noto Sans Ethiopic fallback, loaded via bunny in `vite.config.ts`. Previously rejected directions — dark "night theme v1", soft-card "daylight festival", and the neo-brutalist "street poster" — must not be reintroduced; any further restyle must start from a stakeholder-provided reference.

## Page openers: light `PageHeader` for content pages, `stage` only where it earns it
Content pages (nominees, leaderboard, how-to-vote, prizes, winners, me) open with the LIGHT `PageHeader` (pill badge + display title + lead + tool row) on the ivory ground — high contrast, compact, modelled on the stakeholder's reference site (mpesa2026.lovable.app). The night `stage` utility (literal hex colours, rings pattern, white text — deliberately NOT theme variables so a stale CSS pipeline can never leave white copy on ivory) is reserved for the home hero, the weekly-draw + CTA sections, the creator headliner banner, checkout/status/login cards, header (`stage-flat`) and footer. Never combine `bg-night bg-rings text-white` by hand — use `stage` / `stage-flat`.

## Building blocks (reuse, don't re-invent)
`components/voter/`: `SectionHeading` (glyph + uppercase eyebrow + display title + lead, `tone="dark"` on night), `PageHeader` (light page opener, `live` adds the pulsing dot), `Reveal` (IntersectionObserver fade-up with `delay` stagger — wrap grid items, never whole pages), `CreatorPinwheel` (hero centerpiece), `FaqAccordion` (gradient-frame accordion fed from `faq.q1..q5/a1..a5` lang keys), `PinwheelGlyph`, `NomineeCard` (reference-style card: pastel cover from `coverFor(id)` or portrait, rank + category pills, name, city, approx votes + share-of-voice pill, "Vote · :price ETB" straight to checkout + "Profile"; accepts `query` to carry `?qty=`; price comes from the shared `pricing.unit_etb` prop — never hardcode 10), `NomineeAvatar` (always used for faces), `Countdown` (`tone="dark"`, `size="lg"`), `LocaleToggle` (`tone`), `BrandMark` (exported from `site-header.tsx`). Button variants: `default` (brand gradient), `gold`, `light`, `glass` (on night), `outline`, `secondary`, `ghost`; sizes `sm|default|lg|xl|icon`. Leaderboard is a table card (rank circle, avatar + name, category, city, approx votes, share bar + share-of-voice %, vote button) fed by `PublicBoardPresenter` (`share` = % of leader for bars, `share_pct` = % of all votes). Tab-card lists (categories on home) use the pattern: white pill cards, active = `bg-brand text-white shadow-glow`, content panel with `animate-in fade-in slide-in-from-right-6`.

## Layout + routing conventions
`app.tsx` wraps every page with `layouts/voter-layout.tsx` via the Inertia v3 `layout: () => VoterLayout` resolver — pages do not set their own layout. All voter routes are locale-prefixed (`/{locale}/...`, en/am); build links with Wayfinder helpers from `@/routes` passing `locale` from `useT()` (e.g. `nomineesIndex(locale).url`, `nomineesIndex({ locale }, { query })`) — never hardcode URL strings. A pre-chosen vote quantity travels as `?qty=` from the home package pills → nominees index → creator page → checkout; keep it on those links. Shared props are typed in `resources/js/types/index.ts` (`SharedData`, `PublicStanding`) and `types/global.d.ts`; update both together when `HandleInertiaRequests` changes.
